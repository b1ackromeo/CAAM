## 📌 Repository Overview

This repository contains the comprehensive business proposal, interactive slide decks, technical architecture, and multimedia keynote presentations for modernizing the **Civil Aviation Authority of Malaysia (CAAM)**.

### 🌟 Key Platforms & Presentations

1. **CAD 14 E-Application & AOL Compliance Deck:**
   * File: `cad14_presentation.html`
   * Dedicated 12-slide technical & commercial deck based on `SOLUTIONS_FOR_CAAM.pdf` and `CAD-14-Vol-I`.
   * Covers: 3D OLS Ray-tracing (Chapter 4), IoT AOL sensor telemetry across 9 structure classes (Chapter 6 & Section 24O), and the 80:20 PPP revenue sharing model generating up to RM 163.5M/year.

2. **CAAM 2030 Unified Aviation Portal Master Deck:**
   * File: `presentation.html`
   * Complete 20-slide strategic transformation deck covering personnel licensing, airworthiness, flight operations, drone UTM, and the 150+ manual forms digital migration pipeline.

3. **Multimedia Keynote & Video Streamer:**
   * File: `video.html`
   * Complete high-definition video keynote with neural voiceover narration (`en-US-JennyNeural`).
   * Master Video (1080p): `CAAM_2030_Presentation.mp4`
   * Mobile/WhatsApp Edition (720p · 8.6 MB): `CAAM_2030_Presentation_WhatsApp.mp4`

4. **Comprehensive Business Proposal:**
   * File: `CAAM_Comprehensive_Business_Proposal.md`
   * Full technical design, financial sensitivity analysis, regulatory compliance mappings, and implementation roadmap.

## 🚀 Local Deployment & Viewing

To run locally with Laragon / local HTTP server:
1. Clone repository to your web directory:
   ```bash
   git clone https://github.com/b1ackromeo/CAAM.git
   ```
2. Open in browser:
   * CAD 14 Deck: `http://127.0.0.1/CAAM/cad14_presentation.html`
   * Master Deck: `http://127.0.0.1/CAAM/presentation.html`
   * Video Player: `http://127.0.0.1/CAAM/video.html`
